# raft-rx C demo app

Aplicación independiente de ejemplo que usa la librería `raft_rx` desde C.

## Build

Desde la raíz del repositorio:

```bash
make -C c/examples/demo_app
```

## Run

Desde la raíz del repositorio:

```bash
./c/examples/demo_app/build/raft_kv_demo_app
```

## Limpieza

```bash
make -C c/examples/demo_app clean
```
